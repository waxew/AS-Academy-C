# راهنمای پاسخ تمرین ها

پاسخ تمرین ها باید پس از تلاش هنرجو استفاده شوند. هدف این پوشه ارائه یک implementation مرجع است، نه تنها راه حل ممکن.

قواعد پاسخ مرجع:
- کامنت آموزشی برای بخش های غیر بدیهی
- بررسی خطا متناسب با سطح تمرین
- build بدون warningهای شناخته شده پروژه
- توضیح trade-off در صورت وجود چند طراحی معتبر
