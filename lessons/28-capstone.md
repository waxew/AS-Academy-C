# درس 28 - پروژه نهایی AS Academy C

## هدف
ترکیب تمام مهارت ها در یک پروژه چندماژوله قابل build، test و مستندسازی.

## پیشنهاد پروژه
File-backed Key-Value Store با CLI.

## اجزا
- CLI parser
- Storage engine
- Serialization format
- Dynamic collection/index
- Error model
- Tests
- CMake
- Documentation

## الزامات
1. warningهای اصلی compiler پاک باشند.
2. allocation و file errors مدیریت شوند.
3. APIها header مشخص داشته باشند.
4. ownership مستند باشد.
5. sanitizer run برای testها انجام شود.
6. README روش build و architecture را توضیح دهد.

## معیار پایان دوره
هنرجو باید بتواند علت تصمیم های memory/API/build خود را توضیح دهد، نه اینکه فقط پروژه را اجرا کند.
