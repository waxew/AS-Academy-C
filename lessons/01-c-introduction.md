# درس 01 - آشنایی با زبان C

## هدف
درک جایگاه C، کاربردهای آن و تفاوت استانداردهای مهم زبان.

## C چیست؟
C یک زبان کامپایل شونده و عمومی با کنترل سطح پایین مناسب روی حافظه و داده است. این زبان پایه بسیاری از سیستم عامل ها، runtimeها، کتابخانه های سیستمی، firmwareها و ابزارهای توسعه است.

## چرا C مهم است؟
- مدل حافظه و pointer را شفاف آموزش می دهد.
- برای System Programming و Embedded بسیار مهم است.
- ABI بسیاری از سیستم ها حول C شکل گرفته است.
- بسیاری از زبان ها و APIها امکان FFI با C دارند.

## استانداردها
در طول دوره تفاوت های مهم C89/C90، C99، C11، C17 و C23 معرفی می شوند. مبنای محتوای جدید دوره C23 است، اما portability همیشه در نظر گرفته می شود.

## تمرین
سه نرم افزار یا سیستم معروف پیدا کنید که بخش مهمی از آن ها با C نوشته شده و دلیل مناسب بودن C را برای هر مورد توضیح دهید.

## جمع بندی
هدف دوره فقط حفظ Syntax نیست؛ باید مدل اجرای برنامه، حافظه، Toolchain و طراحی API در C را بفهمید.
