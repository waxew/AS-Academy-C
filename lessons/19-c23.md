# درس 19 - C23 و Modern C

C23 نسخه منتشرشده جدید استاندارد C در زمان تدوین این دوره است. Toolchainها ممکن است سطح پشتیبانی متفاوتی از featureها داشته باشند.

## رویکرد دوره
- Feature را فقط پس از بررسی compiler support استفاده کنید.
- portability requirement پروژه را مشخص کنید.
- fallback یا minimum compiler version را مستند کنید.

موضوعات این بخش شامل تغییرات type/literal، attributeها، `nullptr` و قابلیت های مدرن مرتبط با C23 است.

## تمرین
نسخه compiler خود را بررسی و فهرست featureهای C23 پشتیبانی شده مورد نیاز پروژه را مستند کنید.
