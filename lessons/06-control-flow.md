# درس 06 - شرط و حلقه

## ابزارها
`if/else`, `switch`, `for`, `while`, `do while`, `break`, `continue`.

## انتخاب ساختار
`for` برای iteration شمارشی، `while` برای تکرار مبتنی بر condition و `do while` زمانی مفید است که بدنه باید حداقل یک بار اجرا شود.

```c
for (int i = 0; i < 10; ++i) {
    /* ده بار اجرا می شود. */
}
```

## خطای رایج
شرط پایان اشتباه می تواند out-of-bounds یا infinite loop ایجاد کند.

اعداد اول 2 تا 100 را چاپ کنید و سپس الگوریتم را از نظر تعداد عملیات بهتر کنید.
