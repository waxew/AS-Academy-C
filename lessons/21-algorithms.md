# درس 21 - Algorithms و Complexity

## Complexity
Big-O زبان تقریبی تحلیل رشد هزینه است و جای benchmark واقعی را نمی گیرد.

## مباحث
Linear/Binary Search، sorting، recursion/iteration و trade-off حافظه/زمان.

کتابخانه استاندارد C ابزارهایی مثل `qsort` و `bsearch` دارد که callback comparator دریافت می کنند.

## تمرین
Insertion Sort و `qsort` را روی datasetهای مختلف مقایسه و زمان گیری کنید.
