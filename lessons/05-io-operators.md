# درس 05 - ورودی، خروجی و عملگرها

## هدف
کار با streamهای استاندارد و expressionهای پایه.

`printf` برای خروجی format شده و `scanf` برای ورودی ساده قابل استفاده است؛ با این حال ورودی واقعی باید با دقت اعتبارسنجی شود.

```c
int age;
if (scanf("%d", &age) != 1) {
    /* ورودی معتبر نیست. */
}
```

## گروه های عملگر
Arithmetic، comparison، logical، assignment، increment/decrement و bitwise.

## نکته
Precedence را یاد بگیرید اما برای expressionهای پیچیده از پرانتز استفاده کنید تا intent روشن بماند.

## تمرین
ماشین حسابی بسازید که ورودی نامعتبر و تقسیم بر صفر را مدیریت کند.
