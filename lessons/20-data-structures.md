# درس 20 - Data Structures در C

ساختمان داده در C فرصت خوبی برای تمرین ownership، pointer و API design است.

## مسیر
Dynamic Array → Linked List → Stack/Queue → Hash Table → Tree.

هر implementation باید قرارداد create/destroy، ownership element، failure behavior و complexity عملیات را مشخص کند.

## تمرین
Linked List generic طراحی کنید و تست insert/remove/search بنویسید.
