# درس 25 - Embedded C

در Embedded محدودیت حافظه، زمان، انرژی و سخت افزار روی طراحی اثر مستقیم دارند.

## مفاهیم
Memory-mapped I/O، bit mask، state machine، interrupt concepts و `volatile`.

`volatile` ابزار synchronization بین threadها نیست؛ معنای آن را با atomic اشتباه نگیرید.

## تمرین
بدون سخت افزار واقعی یک register map شبیه سازی و LED state machine طراحی کنید.
